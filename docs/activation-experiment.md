# Experimento de activación · Activation experiment

Estado: preparado, no ejecutado. Duración propuesta: dos semanas desde la publicación comprobada. Objetivo: determinar si personas que ya trabajan en chats largos consiguen un traspaso útil y vuelven a utilizarlo. No prometer mejora de conversión por estos cambios.

## Recorrido

1. Seleccionar diez participantes voluntarios que ya usen Grok Bot con trabajo pendiente en una charla larga. No publicar sus identidades, mensajes ni archivos.
2. Observar sin instrucciones iniciales si entienden para quién sirve la web y qué botón usar. Anotar el primer bloqueo.
3. Pedir que instalen la skill en el bot existente y guarden un punto de control. Verificar la confirmación del bot: copiar el prompt no acredita instalación.
4. Revisar objetivo, decisiones, tareas y referencias. Registrar omisiones, correcciones y tiempo hasta el primer resultado útil.
5. Solo si lo autorizan, realizar el traspaso y comprobar continuación, archivos, conectores y rutinas. Conservar el original como respaldo. No presentar la animación del panel como migración real.
6. A los siete días, preguntar si lo han utilizado de nuevo y para qué. Registrar también los abandonos y su motivo.

## Registro mínimo

| Campo | Qué registrar |
|---|---|
| Participante | Identificador anónimo |
| Canal | Dónde conoció el producto |
| Comprensión | Puede explicar la utilidad y elegir un recorrido |
| Instalación | Confirmada por el bot / no confirmada |
| Primera utilidad | Punto de control revisado y aceptado; tiempo y correcciones |
| Continuación | Tarea retomada y accesos comprobados / bloqueada / no intentada |
| Segundo uso | Confirmado a los siete días / no / sin respuesta |
| Bloqueo | Motivo genérico, sin contenido privado |

Visitas y clics: usar solo estadísticas agregadas ya disponibles del alojamiento, si existen. Esta entrega no instala rastreadores ni recopila chats. Si no hay medición, indicar «no disponible»; no sustituir visitas por estrellas ni instalaciones por clics. No se puede deducir una tasa de conversión global de diez entrevistas.

## Decisión al terminar

- No llegan visitantes adecuados: revisar distribución y el canal de adquisición.
- Llegan pero no entienden o no instalan: ajustar mensaje y acceso.
- Instalan pero no consiguen utilidad: corregir el primer recorrido y los bloqueos.
- Consiguen utilidad pero no repiten: investigar frecuencia de necesidad y motivos antes de añadir variantes.

## Prueba separada de informes recurrentes

Usar datos de prueba autorizados: una rutina existente y un informe con una clave repetida al menos tres veces. Verificar una sola propuesta por clave, rechazo sin insistencia, confirmación antes de cambios, reutilización de Page/rutina, fuente y zona horaria, descarga correcta y fallo visible con última actualización correcta. No dar el modo por activado si no se verifica. No ejecutar esta prueba automáticamente al desplegar la web.

English: this is a prepared two-week, ten-volunteer activation study, not completed research. Count confirmed installation, a reviewed checkpoint, verified continuation and repeat use separately. Use existing aggregate hosting metrics only if available. Test recurring-report success and failure with authorized sample data; do not schedule work or contact participants as part of deployment.
