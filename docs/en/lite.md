# Context Bot Lite

The light version of Context Bot: **just the traffic light and `STATUS.md`**.

- Checks chat size roughly every 20 messages, or when you ask "what colour are we?".
- Saves progress in `STATUS.md` on yellow or red, so you can pick up where you left off.
- No savings mode, no scripts, no handoff or migration.
- At red it suggests **Context Bot Migrator** to move to a fresh bot.

## Which one?

| | Lite | Context Bot |
|---|---|---|
| Traffic light and STATUS.md | ✅ | ✅ |
| Check frequency | ~20 messages | ~10 messages |
| Handoff file (TRASPASO.md) | — | ✅ |
| Savings mode with scripts | — | ✅ |
