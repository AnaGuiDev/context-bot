# Context Bot Lite

La versión ligera de Context Bot: **solo el semáforo y el `STATUS.md`**.

- Revisa el tamaño de la charla más o menos cada 20 mensajes, o cuando preguntas «¿qué color estamos?».
- Guarda el progreso en `STATUS.md` al pasar a amarillo o rojo, para que retomes donde lo dejaste.
- Sin modo ahorro, sin scripts, sin traspaso ni migración.
- En rojo te sugiere **Context Bot Migrator** para pasar a un bot nuevo.

## ¿Cuál elijo?

| | Lite | Context Bot |
|---|---|---|
| Semáforo y STATUS.md | ✅ | ✅ |
| Frecuencia de revisión | ~20 mensajes | ~10 mensajes |
| Archivo de traspaso (TRASPASO.md) | — | ✅ |
| Modo ahorro con scripts | — | ✅ |
